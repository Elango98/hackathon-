# 🏥 Smart Hospital Queue & Patient Flow Management System

An AI-powered hospital queue management system designed to reduce patient waiting time, improve hospital workflow, and provide efficient patient flow management.

## 🚀 Project Overview

The Smart Hospital Queue & Patient Flow Management System helps hospitals manage patients, doctors, tokens, and queues digitally.

The system provides separate interfaces for patients, doctors, and administrators.

## ✨ Features

- 🎫 Online Token Booking
- 👨‍⚕️ Doctor Dashboard
- 👨‍💼 Admin Dashboard
- 🏥 Patient Queue Management
- 📊 Patient Flow Management
- 🗂️ Patient Data Management
- 🩺 Doctor Information Management
- 🤖 AI Voice Assistant
- ⚡ Real-time Token Status
- ⏱️ Reduced Patient Waiting Time
